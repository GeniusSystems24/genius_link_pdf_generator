Overview

ما هي المكتبة؟

طبقة تطبيقية فوق أدوات PDF منخفضة المستوى، مصممة لتوحيد إنشاء المستندات والتعامل معها داخل تطبيقات Flutter.

متى تستخدمها؟

تقارير، فواتير، كشوف، سندات، نماذج أو مستندات أعمال متعددة الصفحات.
مستندات عربية أو إنجليزية أو ثنائية اللغة مع RTL/LTR.
جداول كبيرة تحتاج انتقال صفحات تلقائي دون تداخل مع Header/Footer.
تحتاج Generate/Save/Open/Share/Print من واجهة واحدة.
تحتاج معالجة PDF موجود: merge/split/extract/rotate/watermark/inspect.

فلسفة الحزمة

القوالب طبقة اختيارية وليست جوهر المكتبة. يمكنك بناء كل مستند مباشرة عبر GeniusPdfDocumentBuilder، أو استخدام Fluent Report Composer، أو إنشاء طبقة قوالب خاصة بتطبيقك.

المكتبة تتوقع أن يوفّر التطبيق المضيف الخطوط والصور المطلوبة، خصوصًا خطوط TrueType الداعمة للعربية.

Quick Start

البدء السريع

للتكاملات الجديدة استخدم الـentrypoint المركز، وحمّل الخطوط مرة واحدة ثم مررها إلى إعدادات المستند.

pubspec.yaml
dependencies:
  genius_link_pdf_generator: ^3.7.0

flutter:
  assets:
    - assets/fonts/NotoSansArabic-Regular.ttf
    - assets/fonts/NotoSansArabic-Bold.ttf
    - assets/images/company_logo.png
Entry point
import 'package:genius_link_pdf_generator/
genius_link_pdf_generator_api.dart';

// Full backward-compatible API:
import 'package:genius_link_pdf_generator/
genius_link_pdf_generator.dart';
Configuration
final config = GeniusPdfConfig(
  baseFontBytes: regularFontBytes,
  boldFontBytes: boldFontBytes,
  textDirection: TextDirection.rtl,
  pageSize: GeniusPdfPageSize.a4,
  margins: PdfMargins()..all = 24,
);
Generate & Open
const client = GeniusPdfClient();

final result = await client.generateAndOpen(
  builder: SalesReportDocument(
    config: config,
    reportTitle: 'Sales Report',
    lines: lines,
  ),
  fileName: 'sales_report',
);
Builder API

الـbuilder يتولى تدفق المحتوى، موضع الرسم، والمساحة المحجوزة للرأس والتذييل.

remainingHeightالمساحة المتبقية فوق Footer المحجوز.
canFit(height)التحقق من أن كتلة محتوى ستناسب الصفحة الحالية.
addLine / addRichTextنص متدفق أو نص منسق.
addHeader / addFooterرأس وتذييل متكرر مع احتساب المساحة في page flow.
addGridجدول بيانات يدعم الانتقال بين الصفحات.
addSummary / addGridWithSummaryمجاميع وملخصات مرتبطة بالجداول.
addInfoBox / addReportHeaderمكونات معلومات وعناوين تقارير منظمة.
addQRCodeإضافة رمز QR داخل المستند.
addTwoColumnsتخطيط مخصص بعمودين.
addImage / addAttachmentsصور، مرفقات، وصفحات صور مخصصة.
addBulletListقوائم نقطية أو مرقمة.

Architecture

المعمارية والتكامل

المكتبة تفصل بين واجهة الاستخدام وخدمات التطبيق والبنية التحتية لتسهيل الاستبدال والاختبار.

واجهات الاستخدام

GeniusPdfClient هو facade المقترح للكود الجديد. ما زال GeniusPdfService متاحًا للتوافق مع التطبيقات القائمة. كما تتوفر Controllers لمسارات generation وpreview.

Ports & Adapters

يمكن تبديل generation، file storage، platform interaction، logging، وdocument processing adapters، وهو مناسب للاختبارات ولتخصيص البيئة دون ربط منطق التطبيق مباشرة بالبنية التحتية.
